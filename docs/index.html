SEO Brain

A chat workspace for search work. It reads your notes and the files you give it, and with your own keys it asks Search Console, Analytics, PageSpeed, CrUX and Ahrefs. Postgres runs inside the app.

What you can do with it

Ask about your site

Search Console analytics, quick wins, period comparisons and technical checks. GA4 traffic. PageSpeed and CrUX field data. Each source turns on when you add its key.

Research keywords and links

Ahrefs domain rating, organic keywords, backlinks, competitors, SERP overview, keyword ideas, site-audit issues and internal links. 25 Ahrefs tools, with the API budget shown.

Read the live web

Web search, fetch and render a page, a Lighthouse audit, Google organic results and Google AI Mode answers for a query.

Work with your own material

Upload files and save outputs. Search your past articles and find similar ones. A content calendar, task plans, custom agents and personas.

How it runs

  • The window opens at once and shows a start screen while the local database and API come up. The first launch takes longer, because it creates the database.
  • Postgres runs inside the app, with pgvector. It is the same SQL the server edition runs.
  • Chat needs an Anthropic key, OpenRouter, or any OpenAI-compatible endpoint, including a local model. A missing key is a quiet switch, not a crash.
  • Embeddings are computed on your machine with nomic-embed-text v1 (768 dimensions). The model downloads only after you agree, and the text never goes to the chat endpoint.
  • The same codebase deploys three ways: this desktop app on macOS and Windows, or a Linux server with Postgres.

Concepts and the stack

  • Tauri 2 and Rust for the desktop shell. Express and TypeScript for the API. Next.js for the chat.
  • The Anthropic SDK, and tool calling across 49 tools (48 in the desktop build, which leaves out the knowledge-graph tool).
  • A cheap model routes the tools and a stronger one writes the answer. That split comes from Team Brain, the production system SEO Brain was rebuilt from.
  • Google service-account access for Search Console, GA4, PageSpeed and CrUX.
  • Postgres with pgvector, embedded for the desktop, with 44 migrations.
  • On the server: TimescaleDB, trigram search and a knowledge-graph tool. The desktop build leaves these out.
