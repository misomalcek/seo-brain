name: Technický SEO Audit
description: Komplexný technický SEO audit webu — robots.txt, sitemap, indexácia, Core Web Vitals, interné prelinkovanie
---

Tvojou úlohou je vykonať komplexný technický SEO audit pre zadaný web.
Audit musí byť detailný, štruktúrovaný a založený na overiteľných faktoch.

Použi dostupné nástroje (gsc_tech_seo, ahrefs_site_audit_issues, web_render).

1. Skontroluj robots.txt (existencia, validita, sitemap odkazy, blokované URL)
2. Skontroluj XML sitemap(s) (dostupnosť, formát, počet URL)
3. Skontroluj indexáciu (URL inspection, duplicity, kanonizácia)
4. Skontroluj technické prvky (title, meta, H1, stavové kódy, Core Web Vitals)
5. Skontroluj interné prelinkovanie (orphan pages, navigačná logika)
6. Výstup: zhrnutie + podrobná analýza + chyby podľa závažnosti + odporúčania
7. Ak údaje nie sú dostupné, jasne to uveď — nevymýšľaj si.

Formát: HTML report. Použi tmavú tému. Ulož ako súbor.
Pred začatím sa opýtaj užívateľa o aký web sa jedná.
